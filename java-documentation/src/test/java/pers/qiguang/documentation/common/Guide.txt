电商平台的商品中心数据库设计是一个复杂而重要的模块，需要支持海量商品数据管理、多维度分类、灵活属性扩展和高效查询。以下是典型电商系统（如淘宝、天猫、京东）的核心表设计及说明：

1. 商品主表 (spu_info)
设计目的：存储商品SPU（Standard Product Unit）基础信息，同一SPU下包含多个SKU变体
字段说明：

字段名	类型	说明
spu_id	bigint	主键，商品唯一标识（自增或雪花算法生成）
spu_name	varchar(255)	商品名称（如"iPhone 15 Pro"）
category_id	int	关联商品类目ID
brand_id	int	关联品牌ID
status	tinyint	商品状态（0-下架，1-上架，2-待审核）
description	text	商品详情描述（支持富文本）
create_time	datetime	创建时间
update_time	datetime	最后更新时间
audit_status	tinyint	审核状态（0-未提交，1-审核中，2-通过，3-驳回）
关联关系：

通过category_id关联category类目表

通过brand_id关联brand_info品牌表

一对多关联sku_info表

2. 商品类目表 (category)
设计目的：实现商品分类体系（三级分类常见）
字段说明：

字段名	类型	说明
category_id	int	主键
category_name	varchar(50)	类目名称（如"手机"）
parent_id	int	父类目ID（0表示一级类目）
level	tinyint	层级（1-一级，2-二级，3-三级）
is_leaf	tinyint(1)	是否叶子类目（0-否，1-是）
sort_order	int	排序权重
关联关系：

通过parent_id自关联形成树形结构

关联spu_info表和attribute_key属性表

3. 商品属性表 (attribute_key)
设计目的：管理商品类目的通用属性和销售属性
字段说明：

字段名	类型	说明
attr_id	int	主键
attr_name	varchar(50)	属性名称（如"颜色"、"内存"）
category_id	int	所属类目ID
attr_type	tinyint	属性类型（1-关键属性，2-销售属性，3-扩展属性）
is_required	tinyint(1)	是否必填
input_type	tinyint	输入方式（1-单选，2-多选，3-手工输入）
关联关系：

通过category_id关联类目表

一对多关联attribute_value属性值表

4. SKU表 (sku_info)
设计目的：管理商品最小库存单位（如不同颜色/尺寸的iPhone）
字段说明：

字段名	类型	说明
sku_id	bigint	主键
spu_id	bigint	关联的SPU ID
sku_code	varchar(50)	SKU编码（唯一业务标识）
price	decimal(10,2)	销售价（可能单独拆分为价格表）
stock	int	库存（或关联库存系统）
spec_values	json	销售属性组合（如{"颜色":"黑","内存":"256GB"}）
weight	decimal(8,2)	商品重量（用于运费计算）
is_default	tinyint(1)	是否默认SKU
关联关系：

通过spu_id关联SPU表

多对多关联attribute_value表（通过中间表）

5. 属性值表 (attribute_value)
设计目的：存储具体属性值（如颜色=黑色/白色）
字段说明：

字段名	类型	说明
value_id	bigint	主键
attr_id	int	关联属性ID
value_data	varchar(100)	属性值（如"256GB"）
value_image	varchar(255)	属性图片（如颜色对应的色卡图）
6. 商品图片表 (spu_image)
设计目的：管理商品主图、详情图、SKU图
字段说明：

字段名	类型	说明
image_id	bigint	主键
spu_id	bigint	关联SPU
sku_id	bigint	关联SKU（可为空）
img_url	varchar(255)	图片地址
img_type	tinyint	图片类型（1-主图，2-详情图，3-规格图）
sort	int	排序序号
关键设计特点
SPU-SKU分离
SPU承载商品公共信息，SKU管理具体规格，支持组合属性（如颜色+尺寸）

属性动态扩展
通过属性表与类目绑定，支持不同类目有不同的属性体系

价格库存分离
大型系统会将价格（price_info）、库存（stock_info）单独拆表，支持价格策略和库存分仓管理

图片多用途管理
通过img_type区分主图、详情图、SKU图，支持移动端多尺寸适配

高性能设计

使用JSON字段存储规格组合（如MySQL5.7+的JSON类型）

建立组合索引（如(category_id,spu_id)）

热点数据缓存（如Redis缓存SPU基础信息）

典型业务场景示例

-- 查询手机类目下所有在售的256GB手机
SELECT s.*
FROM spu_info s
JOIN category c ON s.category_id = c.category_id
JOIN sku_info sku ON s.spu_id = sku.spu_id
WHERE c.category_name = '手机'
  AND s.status = 1
  AND sku.spec_values->'$.内存' = '256GB';
