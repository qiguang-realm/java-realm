

当希望AI或读者精准理解您“想要某种古文表达”的意图时，确实有一套高效的沟通模板。


核心原则：提供“三要素”
要让对方（无论是人还是AI）准确输出您要的古文，请在提问时包含：

1.现代白话原意（您想表达什么）

2.使用场景/情感色彩（褒贬、庄谐、男女、亲疏）

3.风格或字数要求（四六骈文、短句、对仗、典故等）


最佳通用提问格式
“请用古文表达：[现代文原句]。
要求：[风格/字数/情感/人称]。
场景：[谁对谁说，在什么情况下]。”


进阶技巧：给AI“角色+场景”
更精准的方法是为AI设定一个说话者的角色：

“假设你是一位宋代文人，在给心仪的女子写信，想说‘我看上你之后，就觉得你什么都好，以后不管你变成什么样，我都喜欢’。
请写一段古文，用第二人称‘卿’，带一点无可奈何又甘之如饴的感觉。”

“我有个朋友”梗


这个梗的核心意思就是：用“我有一个朋友”作为挡箭牌，来问一些自己不好意思开口的问题。

比较常见的说法有以下几种：

“我有个朋友，他想问XXX……”

“我帮我朋友问的……”

“你说的这个朋友到底是不是你自己？”（这是大家听到“我有个朋友”后，最经典的反问）
