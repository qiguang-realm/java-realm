Linux 命令
========================================================================================================================
sudo su - 是一个组合命令，用于在 Linux 系统中切换用户身份。让我详细解释一下：

命令分解
·  sudo：以超级用户权限执行命令

·  su：切换用户（Switch User）

·  - 或 -l 或 --login：完全登录会话

这个命令的意思是：以 root 用户身份创建一个完整的登录会话。

sudo su -
========================================================================================================================
ll 不是一个标准的 Linux 命令，而是一个常用的命令别名。

ll 通常是 ls -l 的别名，用于以长格式列出目录内容。

# ll 实际上执行的是：
ls -l
========================================================================================================================

mv 是 Linux 中用于移动或重命名文件和目录的命令。

基本语法

mv [选项] 源文件 目标文件

mv dist.zip dist.zip.2025-11-25

========================================================================================================================

unzip 是 Linux 中用于解压缩 ZIP 格式文件的命令。

基本语法

unzip [选项] 压缩文件.zip

# 解压到当前目录

unzip file.zip
========================================================================================================================
clear 是 Linux/Unix 系统中用于清除终端屏幕的命令。

基本用法

clear
========================================================================================================================
tail -f out.log 是一个用于实时监控日志文件内容的命令。

命令分解
tail：显示文件末尾内容

-f：跟随模式（follow），实时显示新内容

out.log：要监控的日志文件


# 实时监控 out.log 文件

tail -f out.log

========================================================================================================================
./start.sh 是执行当前目录下的 start.sh 脚本文件。

命令分解
./：表示当前目录

start.sh：shell 脚本文件名

常见用途
1. 启动应用程序


# 启动 Java 应用
./start.sh

# 启动 Node.js 应用
./start.sh

# 启动 Python 应用
./start.sh

2. 启动服务
# 启动后端服务
./start.sh

# 启动微服务
./start.sh

# 启动定时任务
./start.sh
========================================================================================================================
rm -rf dist.zip 是一个删除文件的命令，具有强制删除的特性。

命令分解
rm：删除命令（remove）

-r：递归删除（recursive）

-f：强制删除（force）

dist.zip：要删除的目标文件


rm -rf dist.zip

这个命令会：强制删除当前目录下的 dist.zip 文件，不进行任何确认提示。
