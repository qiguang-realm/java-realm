全球范围内，金融、会计、法律、国际贸易等专业领域都通用且最标准的“国际资本”专业术语。

在各专业领域里，International Capital 确实是最通用、最核心的标准术语，它泛指跨国流动的资金与资产。

国际资本 (International Capital) = 跨国流动的资金与资产。

根据持有主体：可以划分为私人资本 (Private Capital) 和官方资本 (Official Capital)。
