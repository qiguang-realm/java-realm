⏳ 银行股在金融危机周期的完整演变
银行股的行情不能孤立看待，它在整个危机周期中经历了五个截然不同的阶段，能否买入，完全取决于你在哪个节点进场：

阶段	时间参考（以2008年为例）	银行股表现	背后逻辑
第一阶段：冲击抛售	2008年9月15日-9月18日	暴跌，中行跌9%-17%	恐慌情绪>基本面，一切资产被无差别抛售
第二阶段：政策托底	2008年9月19日左右	汇金宣布增持后，三大行全线涨停	国家信用介入，极度悲观预期的强行扭转
第三阶段：反复磨底	2008年9月下旬-10月底	探底震荡，直至10月27日见底	市场从犹豫到相信，信心缓慢修复
第四阶段：强劲反转	2008年底-2009年8月	银行股指数暴涨121.7%	四万亿刺激+信贷扩张，银行是最大的"顺周期"赢家
第五阶段：估值回归	2009年下半年后	回归常态化，分化加剧	刺激政策边际效应递减
以中行为例，2008年9月19日汇金入市后三大行全线涨停，但要到2009年初才能真正确认反转——期间仍有近三个月的磨底期。在危机最恐慌的时刻看准"国有大行"这个核心逻辑，最终兑现收益的前提是穿越极度不确定的磨底期。
